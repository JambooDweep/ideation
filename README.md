# Ideation

Brainstorming and product requirements (PRDs) for new ideas.

Start with the [Roadmap](ROADMAP.md): the vision for Wear Today, a personal style agent, in seven phases.

## Skills

This repository enables Matt Pocock's skills plugin (`mattpocock-skills`, from the `mattpocock/skills` marketplace) in `.claude/settings.json`. Claude Code offers to install it when you open the repository and trust the folder.

Workflow:

1. `/grill-me`: a structured interview that stress-tests the idea until every decision is settled.
2. `/to-spec`: turns that conversation into a PRD (problem, solution, user stories, implementation and testing decisions, out of scope).

PRDs live in `prds/`:

- [Wear Today](prds/wear-today.md): outfit suggestions from your own wardrobe for an event, occasion and mood.
- [Wear Today Phase 2: Personal stylist agent](prds/wear-today-phase-2-stylist-agent.md): calendar-aware briefings, plans, re-checks and memory.
- [Wear Today Phase 3: Wardrobe manager](prds/wear-today-phase-3-wardrobe-manager.md): trips and packing, automatic capture, usage, clear-outs and care.
